# What's New in 3.6.8

- Faster timeline: the activity timeline now loads instantly and scrolls smoothly, even with thousands of entries
- Apple Watch: time-since values on the watch now stay up to date automatically, no need to re-open the app
- Fixed time picker spinner occasionally selecting the wrong value on iOS
- Sleep summaries on the timeline now calculate total sleep more accurately
- Dashboard cards refresh more reliably when switching between activities
- Added a helpful tooltip explaining how daily sleep totals are calculated
