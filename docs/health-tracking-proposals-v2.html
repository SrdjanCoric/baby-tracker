Health Tracking — Revised Proposals v2

5 approaches incorporating competitive research. Each shows the dashboard card in context and the full logging screen. Health color: warm terracotta #D4836B

Proposal 1
Tabbed Health Hub

Single card showing the last health event. The + button opens a tabbed logging screen (Meds | Temp | Vaccine | Symptoms) — each tab has its own optimized form. Industry-standard approach matching how Huckleberry and Nighp split health into sub-types. Medication tab features pre-loaded meds with auto-recall of last dosage.

Mirrors the existing diaper screen pattern exactly. Tap + to open, first pick the health type (Medication / Temperature / Vaccine / Symptoms) from icon+label+description rows. Selected type reveals its form inline below. Familiar UX — no new interaction patterns to learn.

Proposal 3
Quick Dose Card

Medication-focused since that's the most frequent health action during illness. Card prominently shows medication name + time since last dose + countdown to next dose. Tap + goes straight to medication logging. Temperature, vaccines, and symptoms are accessible via a "More health options" link. Optimized for the 3AM fever scenario.

Proposal 4
Compact Multi-Row

Card has 2-3 compact rows showing the latest value for each health sub-type — all visible at a glance without tapping. Each row shows icon + label + last value. The + button opens the type selector. Best for parents who want a "health dashboard at a glance" on the home screen.

Proposal 5
Contextual Card

Card adapts content based on what's been logged recently. When meds are active → shows dose countdown. When temp was logged → shows reading. When nothing recent → calm "last event" state. No explicit sick/healthy toggle — the card figures it out from the data. Logging flow is always the same type-selector.

Comparison
Side-by-Side Evaluation
Proposal Dashboard Focus Logging Pattern Impl. Effort Tradeoff
1. Tabbed Hub Last health event Tab bar (4 tabs) ⭐⭐ Industry standard. Card is simple but logging screen needs 4 tab views
2. Type-First Last health event Diaper-style type rows ⭐⭐ Matches existing patterns perfectly. Extra tap before form input
3. Quick Dose Medication countdown Medication-first, others via link ⭐⭐⭐ Fastest for most common case. Temp/vaccine feel secondary
4. Multi-Row All sub-types at once Tabs (showing temp tab) ⭐⭐ Most info without tapping. Taller card. Empty rows when healthy
5. Contextual Adapts to recent data Type-first + auto-recall ⭐⭐⭐ Best UX — calm when healthy, urgent when sick. More card logic
