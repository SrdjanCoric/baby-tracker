Same shape as breast. Needs the pumping timer to bank minutes per side the way feeding does, and two new columns.

Rules (breast and pumping)

Start is a timestamp. Moving it slides the whole entry; nothing else changes.

Duration is editable, whole minutes, at least 1. End is read-only = Start + Duration + Paused. Paused comes from the timer, read-only, 0 for manual entries (line then reads only "ends …").

Left / Right minutes: whole minutes, blank allowed, prefilled from the record. Each ≤ Duration. No rule on the sum ("Both" counts twice). Never change on their own; a side that no longer fits turns red and blocks Save.

Finished on is the old Side picker, renamed. Drives the next-side tie-break.

Manual log (pumping)

Same Duration and Left / Right minute fields, optional. No "Paused" text; the line reads only "ends 8:25 AM".

Field order: Start, Duration, paused/ends line, Minutes per side, Finished on, Amount (ml), Notes, Save. The Side picker moves from the top to below the minutes.
